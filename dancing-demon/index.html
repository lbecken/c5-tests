The Dancing Demon

A web recreation of Leo Christopherson’s 1979 TRS-80 classic — compose a tune, choreograph the steps, raise the curtain.

What this is

In 1979 Leo Christopherson wrote an animated tap-dancing demon for the TRS-80 Model I — a machine with 128×48 block graphics and a speaker driven off the cassette port. It was not really a game: you typed in a tune one note per count, strung together eighteen lettered dance steps, chose a speed, and the curtain went up.

This is that toy, rebuilt for the browser. Same shape, same monochrome phosphor, same eighteen steps — but the demon is posed from interpolated keyframes, so he moves the way the original always looked like it was trying to.

How to put on a show

  1. Music — tap out a melody, or load one of the built-in tunes.
  2. Dance — stack up steps by letter. Hover one to watch him rehearse it.
  3. Perform — pick a speed and a repeat count, then hit Raise the curtain.

Straight to the show

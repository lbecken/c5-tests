# c5-tests

Scratch repository for experiments.

## Experiments

- [`dancing-demon/`](dancing-demon/) — a browser recreation of Leo Christopherson's 1979 TRS-80
  *Dancing Demon*: compose a tune, choreograph eighteen lettered steps, and raise the curtain on a
  tap-dancing demon. Vanilla ES modules, Canvas 2D and Web Audio, no build step.
